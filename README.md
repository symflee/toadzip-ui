# toadzip-ui

공공주택 단지와 모집공고를 지도에서 탐색하는 **두꺼비집 UI 프로토타입**입니다.

백엔드와 분리된 화면 구성 검토용 저장소이며, 현재 데이터는 고정된 예시 데이터입니다.

## 제공 화면

- 지도 기반 단지 탐색과 단지 목록
- 단지 상세 정보 및 주택형 비교
- 모집공고 목록과 공고 상세 정보
- 공급 단지별 요약과 주택형 정보
- 검색, 필터, 저장, 신청조건 비교 UI
- 시안 A/B/C 전환

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다.

## 검증

```bash
npm run check
```

## 참고

- 지도는 OpenStreetMap 타일을 사용합니다.
- 저장과 일부 설정은 브라우저의 로컬 저장소에만 보관됩니다.
- 실제 공고문/PDF/API 연결은 아직 예시 동작입니다.
